# Data workstream: first checkpoint findings (2026-11-14)

This file is hand-written. `data_checkpoint.md`, `data_checks.json` and `model_report.*` are generated by the pipeline.
The current generated reports come from a `--skip-census` build, so ACS covariates are null. Do not treat them as release numbers.

## Blockers

1. **Census API key required.** `api.census.gov` now redirects keyless requests to `missing_key.html`. Set `CENSUS_API_KEY` and rerun `parcel-pipeline all`. Until then, `demographics.geoparquet` is not produced and density, income and rent features are null with their flags set.

## Data facts that affect other workstreams

- **Parcel IDs** are `sf:<mapblklot>`. 227,968 active APNs consolidate to 155,028 physical lots, 9,466 of which have multiple APNs (condos). 262 API records have neither `mapblklot` nor geometry and are dropped. All remaining lot geometries are valid.
- **Vacancy:** 8,383 lots are `source_indicated_vacant` (land use 2023 `VACANT`), 9,304 are `unknown` (no land-use match or null code) and 137,341 are `not_vacant`. The land-use snapshot is 2023 and archived, and the UI should show that vintage.
- **Assessor:** the 2025 closed roll matches 211,163 active APNs. 16,543 active APNs have no roll row; their values stay null.
- **SF host moved:** `data.sfgov.org` now returns 301 to `data.sf.gov`. Backend's parcel provider should use the new host.
- **Reviews coverage is tiny.** 213,536 parsed reviews cover 6,108 place IDs, but only 139 of them are in the Places export. `review_summary.parquet` is therefore nearly all zeros, and joined review counts measure sample coverage only. 42,184 reviews have rating 0 (no star value) and are excluded from `mean_rating`.
- **Schools have no review signal.** `reviews_count` is 0 for every school record (476 labeled rows across all three cities), so school is marked as a degenerate target. School review activity is null with no source, rather than a fabricated 0.

## Model (without covariates)

- Oakland/Berkeley sample gates are met by clinic and grocery only. Pharmacy (50/17) and bank_credit_union (75/23) fall back to category baselines.
- On Berkeley, the model was 9.6% better than the category baseline (macro RMSE), so it passed the gate.
- **On the single SF test, the model is worse than the baseline:** clinic RMSE 1.061 vs 0.987, grocery RMSE 2.157 vs 2.033. Within-category Spearman is −0.09 for clinic and 0.13 for grocery. Berkeley selection did not generalize. Rerun with ACS covariates before freezing. If SF still trails the baseline, the team should decide whether to present the baseline review activity per the plan's fallback, even though the Berkeley gate passed.

## Category mapping decisions for team review

See `category_audit_sample.csv`; the `reviewer_verdict` column is empty for manual review.

- **Clinic includes individual "Doctor" listings** (11,593 Bay Area rows). The sample contains non-clinic providers (`JD`, `MFT`, `OD` suffixes), and 80% of clinic rows have 0 reviews. Keeping "Doctor" inflates clinic supply in 2SFCA. Dropping it would shrink clinic supply to facilities. Decide before freezing.
- **Pharmacy includes individual pharmacist listings** (e.g. personal names under category "Pharmacy"). These are probably duplicates of the store they work in.
- **Convenience stores are excluded from grocery** (1,669 + 59 rows). Lookalikes such as "Popeye's Tobacco & Grocery" stay `other`.
- Specialists (surgeons, cardiologists, oncologists), acupuncture, PT and med spas are `other`, not clinic.
